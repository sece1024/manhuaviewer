# Frontend Layout Optimization Plan

## Overview
6 high-impact layout improvements, each a separate commit. Focused on touch targets, responsive behavior, and visual clarity.

## 1. Increase touch targets to 44px minimum
**File:** `frontend/src/index.css`
- `.btn`: `min-height: 38px` → `44px`
- `.btn-icon`: add `min-width: 44px; min-height: 44px`
- `.btn-sm`: `min-height: 32px` → `36px`
- Mobile sidebar nav links: `padding: 8px 12px` → `10px 12px` (min-height 44px)

## 2. Archive grid: adaptive column width
**File:** `frontend/src/index.css`
- `.archive-grid`: `repeat(auto-fill, 160px)` → `repeat(auto-fill, minmax(180px, 1fr))`
- Cards fill available width evenly instead of fixed 160px columns

## 3. Settings: consistent breakpoint + better mobile nav
**File:** `frontend/src/index.css`
- Change settings breakpoint from 720px to 768px (consistent with rest of app)
- Mobile settings nav: larger tap targets, smoother scroll

## 4. Toast: avoid overlapping reader toolbar on mobile
**File:** `frontend/src/index.css`
- Mobile toast: `top: auto; bottom: 120px` (above bottom nav, below reader content)

## 5. History: hide delete button until hover/focus
**File:** `frontend/src/index.css`, `frontend/src/pages/History.js`
- History delete button: `opacity: 0` by default, `opacity: 1` on `.history-item:hover/.focus-within`
- Consistent with Library's hover-to-reveal pattern

## 6. Extract welcome screen inline styles to CSS class
**File:** `frontend/src/index.css`, `frontend/src/pages/Library.js`
- Create `.welcome-screen` class with consistent spacing
- Replace ~15 inline style objects in Library.js welcome screen
