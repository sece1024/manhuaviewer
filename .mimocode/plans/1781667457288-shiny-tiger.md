# Simplify "Open File" Flow

## Problem
After clicking "📂 打开文件" in the toolbar, users must choose between "📁 选择文件夹" and "📄 选择压缩包" — an unnecessary decision. The backend (`api.openFile`) already auto-detects the type from the path.

## Current flow (4 steps)
1. Click "📂 打开文件" → modal opens with text input + 2 buttons
2. Click "📁 选择文件夹" OR "📄 选择压缩包" → Tauri dialog opens
3. Select → path appears in input
4. Click "打开"

## Simplified flow (2 steps)
1. Click "📂 打开文件" → single Tauri file dialog opens directly
2. File opens automatically (backend auto-detects type)

For manual path entry (browser mode or paste):
1. Click "📂 打开文件" → modal with text input only
2. Type path → Enter

## Changes

### File: `frontend/src/pages/Library.js`

**A. Toolbar "打开文件" button** (line 500, line 532):
- In Tauri mode: bypass the modal entirely, open file dialog directly
- In browser mode: open modal (for manual path input)

Replace `setShowOpenModal(true)` with a new `handleQuickOpen` function:
```js
const handleQuickOpen = async () => {
  if (!isTauri) {
    setShowOpenModal(true);
    return;
  }
  try {
    const selected = await window.__TAURI__.dialog.open({
      multiple: false,
      title: '选择漫画文件或文件夹',
      filters: [{ name: '漫画文件', extensions: ['zip', 'cbz', 'rar', 'cbr', '7z'] }]
    });
    if (selected) {
      setOpening(true);
      try {
        const result = await api.openFile(selected);
        toast(result.message || '已打开', 'success');
        navigate(`/reader/${result.id}`);
      } catch (e) {
        toast(e.message, 'error');
      }
      setOpening(false);
    }
  } catch (e) {
    toast('选择文件失败: ' + e.message, 'error');
  }
};
```

Note: The Tauri file dialog shows files by default. Users who want folders can still type the path in the modal (accessible via long-press or if we keep a secondary option).

**B. Modal** (lines 646-693):
- Remove the "📁 选择文件夹" and "📄 选择压缩包" buttons entirely
- Keep the text input for manual path entry
- Update placeholder: "输入文件或文件夹路径，如 /Users/me/manga 或 /Users/me/manga/comic.cbz"
- The modal is now only for browser mode or manual path entry

**C. Welcome screen** (lines 364-373):
- Keep the two separate buttons ("📁 打开文件夹" and "📄 打开压缩包") — this is the first-time experience and the choice is appropriate here
